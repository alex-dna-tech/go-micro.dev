# Learn by Example

> A collection of small, focused examples demonstrating common patterns with Go Micro.

---

Section pages:

- [Hello Service](/docs/examples/learn-by-examples/hello-service/): A minimal HTTP service using Go Micro, with a single endpoint.
- [Rpc Client](/docs/examples/learn-by-examples/rpc-client/): Call a running service using the Go Micro client.
- [Service Discovery with Consul](/docs/examples/learn-by-examples/registry-consul/): Use Consul as the service registry.
- [Store Postgres](/docs/examples/learn-by-examples/store-postgres/): Use the Postgres store for persistent key/value state.
- [Transport Nats](/docs/examples/learn-by-examples/transport-nats/): Use NATS as the transport between services.
